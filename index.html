ORION3: Pre-payment Scam-Risk Scoring

Scores a payment before it completes and returns ALLOW / WARN / BLOCK with plain-language reasons, using payment behaviour, receiver-network and message signals. Served with FastAPI (p95 27 ms).

Benchmarked LightGBM on real IEEE-CIS data (590k transactions, chronological split, untouched holdout): PR-AUC 0.50, ROC-AUC 0.90. Limitations are documented, including a 51% false-alarm rate of the smishing model on formal legitimate messages.

BACKLOT: Distributed Product Returns and Recovery

Event-driven system that reconstructs product-return journeys from independent services. Events enter through a FastAPI gateway into a Kafka-compatible broker (Redpanda). The consumer uses a Postgres idempotency ledger, bounded retries with backoff and a dead-letter topic. Includes reconciliation, a risk model and a small RAG step over versioned policies. All data is synthetic.

Verified run: replayed 1740 events twice and the ledger stayed at 1720 processed rows, with no duplicates.
